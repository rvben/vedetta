People Tracked objects
Object matching runs on this Vedetta server. Reference crops and visual fingerprints are not sent to a cloud recognition service. Deleting a tracked object removes its recognition profile; original events and recordings remain until their retention period ends.

Tracked objects let Vedetta recognize specific things — your car, a delivery van, a family member's bike — across your cameras using a visual fingerprint. When the system sees a known object again, it links the sighting back to its identity.

Add a tracked object from any event by clicking Track as new. Adjust the match threshold per object if you are getting false positives or missed sightings.
