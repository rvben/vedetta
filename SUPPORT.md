# Support

## Getting help

Before opening an issue:

1. Check [README.md](README.md), [docs/CAMERAS.md](docs/CAMERAS.md),
   [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md), and the relevant
   configuration comments in [config.example.yml](config.example.yml).
2. Check the System page, `/api/health`, camera status, and recent logs.
3. Reproduce with the latest released version when possible.
4. Remove credentials, tokens, public IPs, private URLs, database contents, and
   recognizable footage from all diagnostics.

Use a bug report for reproducible defects and a feature request for product
proposals. General configuration questions may use GitHub Discussions when it
is enabled.

Vedetta is community-supported and has no guaranteed response time. Security
issues must follow [SECURITY.md](SECURITY.md).
